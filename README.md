# Лабораторная работа №2. Многопоточное умножение матриц

**Студент:** Фотин Марат, ИТ7
**Оценка:** 4

В данном репозитории реализовано многопоточное умножение матриц на языке C++ (C++20) с ручным управлением потоками `std::thread`, использованием кэш-дружелюбного порядка обхода циклов и балансировкой нагрузки (static/dynamic). Также реализован механизм IPC (Anonymous Pipe) для передачи бинарных данных между процессами.

## Структура репозитория

* `main.cpp` — исходный код основной программы (включает логику всех заданий на оценку «3» и «4»).
* `benchmark.py` — Python-скрипт для автоматического проведения серий замеров (по 5 прогонов с усреднением) и построения графиков (`.png`).
* `results_*.csv` и `*.png` — сохраненные сырые результаты замеров и построенные графики.

## 1. Сборка и запуск основной программы (main.cpp)

Для сборки программы требуется компилятор с поддержкой C++20 (GCC/Clang для Linux/macOS или MSVC для Windows). Сборка обязательно должна производиться с флагом максимальной оптимизации `-O2`.

### Linux / macOS (GCC / Clang):

g++ -O2 -std=c++20 main.cpp -o matmul -lpthread

### Windows

cl /O2 /std:c++20 /utf-8 main.cpp
