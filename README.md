# Фотин Марат ИТ-7 Лабораторная работа № 2. Многопоточное умножение матриц

Программа выполняет умножение двух матриц с использованием потоков C++ (стандарт C++20). Реализовано базовое многопоточное умножение с кэш-дружелюбным обходом памяти, генерация данных в отдельном дочернем процессе с передачей по каналу (Anonymous Pipe), а также сравнение статического и динамического распределения нагрузки на примере нижнетреугольной матрицы.

Во время вычисления отображается прогресс; после завершения выводятся время умножения и контрольная сумма. В проекте также есть скрипт для автоматического проведения серии замеров и отдельный модуль юнит-тестов.

## Требования

- Компилятор C++ с поддержкой стандарта C++20 (GCC, Clang или MSVC);
- Python 3 с библиотеками `matplotlib` и `pandas` (для скрипта замеров);
- Фреймворк GoogleTest (для сборки юнит-тестов).

Для ОС Windows рекомендуется поддержка UTF-8 в консоли.

## Структура проекта

```text
/

├── benchmark.py
└── README.md
```

- `main.cpp` — основной код программы (задания на оценки «3» и «4»).
- `tests.cpp` — юнит-тесты на базе GoogleTest.
- `benchmark.py` — скрипт автоматического запуска замеров и построения графиков.
- `README.md` — инструкция по запуску.

## Сборка и запуск через терминал

Находясь в корневой папке проекта, скомпилируйте файл основной программы. Сборка обязательно должна производиться с включенным флагом максимальной оптимизации (`-O2` или `/O2`).

**Linux / macOS (GCC / Clang):**
```bash
g++ -O2 -std=c++20 main.cpp -o matmul -lpthread
```

**Windows (MSVC):**
```cmd
cl /O2 /std:c++20 /utf-8 main.cpp
```

## Запуск отдельного умножения

Программу можно запустить без аргументов для вызова интерактивного меню:
```bash
./matmul
```

Для запуска программы напрямую через аргументы командной строки используйте следующие форматы:

1. **Обычное многопоточное умножение (Оценка 3):**
   ```bash
   # Быстрый (кэш-дружелюбный) порядок i->t->j
   ./matmul mul 2000 1500 1800 8
   
   # Медленный (школьный) порядок i->j->t (для сравнения)
   ./matmul mul 2000 1500 1800 8 ijk
   ```

2. **Генерация матриц в отдельном процессе и передача по Pipe (Оценка 4, п. 3.1):**
   ```bash
   ./matmul ipc 2000 1500 1800 8
   ```

3. **Нижнетреугольная матрица: Static vs Dynamic (Оценка 4, п. 3.2-3.3):**
   ```bash
   # Статическое распределение (или просто ./matmul 2000 2000 8 static)
   ./matmul tri 2000 2000 8 static
   
   # Динамическое распределение (с порцией по 8 строк)
   ./matmul tri 2000 2000 8 dynamic 8
   ```

## Вывод программы

Матрицы заполняются случайными целыми числами от 0 до 9. Программа выводит:
- прогресс выполнения в процентах;
- время умножения в секундах;
- контрольную сумму элементов результата;
- результирующую матрицу целиком, если её размеры не превышают `10 × 10`.

## Автоматическая серия замеров

1. Убедитесь, что основная программа скомпилирована.
2. Внутри скрипта `benchmark.py` при необходимости задайте верные параметры для вашего процессора в константах `PHYSICAL_CORES` и `LOGICAL_CORES`.
3. Запустите скрипт:

```bash
python3 benchmark.py
```

Скрипт проводит по 5 повторов для каждой комбинации параметров, отбрасывая лучшее и худшее время, и усредняет оставшиеся три значения (согласно методике замеров). Во время работы скрипт передает бинарному файлу флаг `-q` (quiet) для отключения вывода прогресса.

## Файлы результатов

После завершения замеров скрипт сохраняет результаты в текущую папку:
- `results_grade3.csv` — сырые данные и расчеты ускорения/эффективности для обычного умножения.
- `results_grade4.csv` — сравнение статического и динамического распределений.
- `*.png` — автоматически построенные графики по результатам измерений.

## Сборка и запуск юнит-тестов

Для компиляции и запуска тестов требуется фреймворк **GoogleTest** (`libgtest-dev` на Ubuntu, `gtest` на Arch Linux). 

```bash
g++ -O2 -std=c++20 tests.cpp -o run_tests -lgtest -lgtest_main -lpthread
./run_tests
```

Тесты (включая многократные стресс-тесты на 100 итераций) проверяют корректность базового умножения, обработку несовместимых матриц и граничных случаев, перехват исключений, работу статического и динамического распределения, а также целостность бинарных данных при межпроцессном взаимодействии (IPC Pipe).
